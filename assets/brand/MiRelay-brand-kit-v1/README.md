## 本次选定的设计

- **完整字标**：Mi 与 Relay 错层组合，三 i 接力，y 托住文件；使用尾巴已经压低的版本。

## 当前格式与使用边界

**这些 PNG 保留原图的白色背景，没有透明通道。** 图像工具的透明底导出未产生有效 alpha，因此失败结果没有收入素材包。深色背景上会显示白色矩形画布；可在浅色容器中先行接入，透明底版本后续另行制作。

所有尺寸文件均从选定原图按比例缩小，没有重新生成设计。16 / 24 px 是通用缩小版，文件折角在这些尺寸下会变弱；优先以 32 px 及以上展示。原始图保留了展示留白，实际接入可根据容器检查视觉大小。

本包是 **PNG 位图资源**，没有可编辑的 SVG / AI 矢量源文件，也没有独立的前景、背景分层。避免放大超过原始分辨率。

## 外观原则

1. 项目名称写作 `MiRelay`，作者署名写作 `MiiiKuuu`。
2. 保留三 i、墨灰与鼠尾草绿，以及贴纸的白色轮廓和柔和投影。
3. 图标保持等比缩放；完整字标用于较宽的展示区域。
4. 小尺寸图标优先使用独立三 i 标志，完整字标中的小字需要更大的展示宽度。
