# MiRelay 设计交接

## 优先级

以 `preview/desktop.html` 为最新整体视觉基准，以 `preview/mobile-album.html` 为移动相册结构参考。已有项目结构、数据模型与真实功能，以实施时读取的仓库为准。

## 已确认规则

1. 白色毛玻璃，背景为可辨认的缓慢移动光带，色相渐变。
2. 侧栏比主内容更透明；主内容由一整块浅白玻璃承托。
3. 所有 UI 图标使用石墨灰，不以绿色点表达 Paired。
4. 普通文件夹显示文件夹图标，相册显示叠放照片图标；切换类型时主标题图标同步改变。
5. Paired 使用水平 link-2，小尺寸、细线条，与文字对齐，不再额外套徽章。
6. 相册三列、间距 0；缩略图无单独容器装饰、无圆角、无外露说明。照片数量仅顶部显示一次。
7. 大图按原比例显示。桌面支持前后切换及方向键；手机参考还支持滑动。
8. 动画开关在全局 Settings，主页不放动画按钮。
9. 字体采用正常 UI 字体，正文不套艺术字。艺术字仅用于品牌区域，避免影响对齐和阅读。
10. 保留较活泼的品牌字标；标题区使用文件夹类别图标。正式替换前确认所选字标的比例、白底与留白效果。

## 手机参考与最新规则的差异

手机文件页和相册是此前已展示的独立设计参考，未在此次素材打包中再次改版：
- 手机顶栏仍有 Pause；实施时移入全局 Settings。
- 手机文件页的 Paired 图形早于最终 link-2 方案；以桌面及手机相册的 link-2 为准。
- 桌面已有标题类型图标，手机落地时同步。
- 手机侧栏示例尚未连接完整的文件夹切换逻辑。

## 桌面布局与材质

桌面外框最小高度 680，外框圆角 22；布局外留白 14，侧栏宽 208，栏间距 14。
主面板圆角 17；桌面标题及列表统一 28 的水平对齐线。
主体字色 #292d30，次要文字 #62696e，分割线 #353d4312。
玻璃填充、模糊、阴影以 `source/desktop.css` 的最终覆盖规则为准。
图标通常 20–23，线宽约 1.6；主标题类型图标 40，线宽 1.4。
CSS 内的小屏断点为 860 / 760 / 560，最窄布局延续单栏回流。

## 动效

三层光带分别 12 / 15 / 14 秒，色相 22 秒循环；具体路径见原始 CSS keyframes。
采用 transform 移动，并在 reduced-motion、后台标签页、离开视口时停动画。
真实客户端需进一步验证 GPU 合成、耗电、后台行为及玻璃模糊性能。

## 移植建议

先读取 AGENTS.md、项目结构和现有 UI；复用已有功能。将演示数据替换为真实数据，连接配对状态、传输列表、文件夹类型和相册分页。
原生 GTK / Android 与网页 CSS 的模糊、阴影、动画实现方式不同，移植时以视觉规则为目标。
示例地址、校验字符串及文件名来自此前设计参考，不是可直接使用的生产配置。
默认文件夹和相册的区分，应来自真实类型字段，避免通过文件夹名称猜测。
